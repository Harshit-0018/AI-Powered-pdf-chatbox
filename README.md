
# AI PDF Chatbot using RAG (Retrieval Augmented Generation)

## 🚀 Project Overview
This project is an **AI-powered chatbot** that allows users to upload PDF documents and ask questions from them.
It uses **Retrieval Augmented Generation (RAG)** combining:
- Vector search (FAISS)
- OpenAI-compatible LLMs
- Sentence embeddings

This project is resume-ready and demonstrates real-world AI system design.

## 🧠 Features
- Upload and parse PDF files
- Convert text into vector embeddings
- Store embeddings using FAISS
- Query documents using semantic search
- Generate accurate answers using an LLM

## 🛠 Tech Stack
- Python
- LangChain
- FAISS
- SentenceTransformers
- Streamlit
- OpenAI / Ollama compatible models
